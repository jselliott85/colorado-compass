# Colorado Compass

A GeoGuessr-style geography game for Colorado. Real satellite imagery (Esri World Imagery)
for each round's scene, a real topographic reference map (Esri World Topo Map) for guessing,
drawn from a curated pool of 40 Colorado locations (landmarks, reservoirs, ski resorts,
mountain ranges, and small mountain towns).

Static site, no build step, no backend — deploy target is GitHub Pages at
`cocompass.leehilllabs.com`.
