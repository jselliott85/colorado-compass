# Colorado Compass

A satellite geography game for Colorado with two ways to play. Easy mode asks the player to
identify each scene from five same-category locations; Hard mode uses a topographic reference map
(Esri World Topo Map) for point-based guessing. Both use real satellite imagery (Esri World
Imagery) drawn from a curated pool of 68 Colorado locations (landmarks and parks, bodies of
water, ski resorts, mountain ranges and peaks, mountain towns, and cities).

Static site, no build step, no backend — deploy target is GitHub Pages at
`cocompass.leehilllabs.com`.
